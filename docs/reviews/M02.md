## Findings

### F1 — Duplicate detection misses names that differ only in spacing or punctuation (Medium)
- **Ref:** M2-R5
- **Evidence:** `…0003` line 316, index on `lower(legal_name)`. Probe: "Kaveri Fertilisers Ltd" and "Kaveri  Fertilisers Ltd." were **both accepted (201, 201)**.
- **Expected:** Obvious duplicates are caught.
- **Fix:** Compare on a normalised key: lower case, with whitespace and punctuation removed. This works for any script. Do the same for installation names.
- **Retest:** A test with variants in spacing and punctuation.

### F2 — An importer of a deleted client can still be edited and deleted (Medium)
- **Ref:** M2-R6
- **Evidence:** `registry.router.ts` line 58, `loadImporter`, checks only the importer's own `deleted_at`. Probe: after the client was deleted, `PATCH /importers/:id` returned **200**.
- **Fix:** The loader must also require the parent client to be live.
- **Retest:** A test that expects 404.

### F3 — Country doesn't yet drive the defaults (Medium, planned)
- **Ref:** M2-R3, AT1
- Grid factors (M4) and carbon-price rules (M9) don't exist yet. Re-run AT1 once M4 lands.

### F4 — No period check on installation delete (Medium, planned)
- **Ref:** M2-R6, AT3
- The `DELETE /installations/:id` handler notes where M3 plugs in. Close with M3, including AT3 against real periods.

### F5 — Out-of-order autosave responses can show stale values (Low)
- **Ref:** Beyond spec. Traced, not executed.
- **Evidence:** `RecordForm.tsx` line 81. Two quick blurs send two PATCH requests at once. If the first response arrives last, `setQueryData` puts the older record back in the form, although the database holds the newer one.
- **Fix:** Send saves one after the other, in order.
- **Retest:** A web test with a delayed first response.

### F6 — Coordinates are shown without a unit (Low)
- **Ref:** Design system §3.4, §13 ("units next to every number")
- **Evidence:** `sections.ts` line 48. The unit appears only in the hint text.
- **Fix:** Put the unit (°) with the field.

### F7 — The importer dialog button and the audit entry use different verbs (Low)
- **Ref:** Design system §9, §13 ("same verb on button, toast and audit")
- **Evidence:** The button says "Save importer" and the toast "Importer saved", but the audit action is "Edit importer" (`registry.router.ts` line 259).
- **Fix:** Use "Save importer" in the audit entry too.

### F8 — EU countries are accepted as installation countries (Info → Spec gap)
- **Ref:** Spec gap. Probe: `DE` gets **201** and `EU` gets **201**.
- CBAM installations are outside the EU, but whether to block or warn is a regulatory rule. It belongs in the M4 configuration, not in code (CLAUDE.md rule 9). Not changed.

### F9 — Everyone with access to a client sees the whole team's names and emails (Info → Spec gap)
- `/clients/:id/team` and the widened `app_user` read policy let a contributor see the names and emails of everyone assigned to that client. The team list needs this, but the spec says nothing about it.

### F10 — G5/G7 don't say whether they cover identification numbers (Info → Spec gap)
- Coordinates are numeric, but they aren't activity data. I treated them as exempt from unit and provenance. The spec should say so.

### F11 — The template's country list includes codes that aren't ISO 3166 (Info → Spec gap)
- `EU`, `XI`, `XK` and `ZR` come from the official template list. M2-R3 says ISO 3166. The template wins for export, so the spec wording should be updated.

## Spec gaps
1. **EU countries (F8):** should an installation in an EU member state, or with the code `EU`, be blocked or trigger a warning? This needs a configuration flag in M4.
2. **Team visibility (F9):** which roles may see the rest of a client's team, and their contact details?
3. **G5/G7 scope (F10):** do they exempt identification data such as coordinates?
4. **M2-R3 wording (F11):** it should say "template country list" rather than ISO 3166.
5. **Map preview (design system §6.2):** a small map preview needs a map-tile provider, which sends the coordinates to a third party. For now it is an explicit external link. Choose a provider, or confirm the link is enough.
